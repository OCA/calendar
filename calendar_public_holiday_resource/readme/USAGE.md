Public holidays are synchronised automatically whenever a public holiday, a
working schedule or a company country changes, and a daily scheduled action
keeps the next two years in step.

To synchronise by hand, select one or more public holiday calendars in the list
and run **Synchronise Public Holidays** from the actions menu. It reports how
many entries were created, adopted, updated or removed, and names any public
holiday that generated nothing.

**Create Next Year** on the same list copies a year of public holidays onto the
following year; the copies are synchronised as they are created.

Global time off generated this way is read-only; edit the public holiday
instead. Global time off that was entered by hand is never touched, except that
a single-day record matching a public holiday is adopted so that no duplicate is
created.

The standard public holiday list gains a **Public Holiday** column and two
filters, *From Public Holidays (OCA)* and *Not From Public Holidays (OCA)*, so
that entries kept by hand can be told apart from the generated ones and cleaned
up. They can also be grouped by public holiday.

If a public holiday generates no time off at all, the public holiday form says
so and why -- most often because no company has a country set, or because
nobody is assigned to the regions the holiday belongs to.
